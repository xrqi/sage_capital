# 周报生成器

## 使用场景

- 用户要求"帮我写周报"
- 用户需要总结本周工作进展
- 用户需要向团队/上级汇报工作

## 周报结构模板

```markdown
# 周报 - [日期范围]

## 本周完成工作

### 1. [项目/任务名称]
- **状态**: 已完成 / 进行中 / 延期
- **内容**: 简要描述完成的工作内容
- **成果**: 具体的产出或成果

### 2. [项目/任务名称]
...

## 下周计划

### 1. [计划任务名称]
- **目标**: 要达成的具体目标
- **预计完成时间**: 

### 2. [计划任务名称]
...

## 遇到的问题与风险

| 问题 | 影响 | 解决方案/状态 |
|------|------|---------------|
| 问题描述 | 影响范围 | 当前状态 |

## 需要的支持

- [ ] 需要的资源或协助

## 其他事项

- 备注信息
```

## 信息收集

生成周报前，收集以下信息：

1. **时间范围**: 
   - **优先从用户提供的文档中提取日期信息**（如："2026年3月24日 - 2026年3月28日"）
   - 如果文档中没有明确日期，询问用户
   - 格式要求：必须在周报标题中显示完整的日期范围

2. **工作内容**: 
   - 读取用户上传的文档内容
   - 检查 git 提交历史
   - 查看项目中的 TODO/任务列表
   - 询问用户补充信息

3. **项目进展**: 各任务的完成状态和成果
4. **问题与风险**: 遇到的阻碍或需要关注的事项

## 生成步骤

1. **提取日期范围（关键步骤）**
   - **首先检查用户上传的文档**，寻找日期信息
   - 常见格式："2026年3月24日 - 2026年3月28日"、"时间范围：3月24日-28日"、"本周（3.24-3.28）"
   - **必须将提取的完整日期范围放入周报标题**
   - 示例：文档中有"2026年3月24日 - 2026年3月28日" → 周报标题为"# 周报 - 2026年3月24日-3月28日"

2. **收集工作信息**
   - 读取用户上传的文档内容
   - 查看 git log 获取代码提交记录
   - 检查项目中的任务文件或 TODO 列表
   - 请用户补充未记录的工作内容

3. **整理并分类**
   - 按项目/模块分类
   - 标注完成状态
   - 提取关键成果

4. **生成周报**
   - **标题必须包含从文档中提取的完整日期范围**
   - 使用上述模板填充内容
   - 确保语言简洁、专业
   - 突出关键成果和进展

5. **输出格式**
   - 默认输出 Markdown 格式
   - 如用户需要，可转换为其他格式

## 日期提取规则

当用户上传文档时，按以下优先级提取日期：

1. **查找明确的日期范围声明**
   - "时间范围：2026年3月24日 - 2026年3月28日"
   - "日期：3月24日-28日"
   - "本周（2026.3.24-2026.3.28）"

2. **提取并格式化**
   - 保持原始日期的年月日信息
   - 格式："# 周报 - [年]年[月]月[日]日-[月]月[日]日"
   - 示例："2026年3月24日 - 2026年3月28日" → "# 周报 - 2026年3月24日-3月28日"

## 示例

**用户输入**: 上传包含日期"2026年3月24日 - 2026年3月28日"的工作内容文档

**执行过程**:
1. **提取日期**：从文档中找到"2026年3月24日 - 2026年3月28日"
2. 读取文档中的工作内容
3. 整理工作项并按项目分类
4. 生成完整周报（标题使用提取的日期）

**输出示例**:
```markdown
# 周报 - 2026年3月24日-3月28日

## 本周完成工作

### 1. 用户认证模块开发
- **状态**: 已完成
- **内容**: 实现 JWT 登录认证功能
- **成果**: 完成登录/注册 API，集成前端登录页面

### 2. 数据库优化
- **状态**: 进行中（80%）
- **内容**: 优化用户表查询性能
- **成果**: 添加索引，查询速度提升 50%

## 下周计划

### 1. 完成数据库优化
- **目标**: 完成剩余表的索引优化
- **预计完成时间**: 周二

### 2. 开始支付模块开发
- **目标**: 完成支付接口设计
- **预计完成时间**: 周五

## 遇到的问题与风险

| 问题 | 影响 | 解决方案/状态 |
|------|------|---------------|
| 第三方登录 API 文档不完整 | 影响微信登录开发 | 已联系技术支持，等待回复 |

## 需要的支持

- [ ] 申请测试环境服务器资源

## 其他事项

- 无
```
